# Kota Rail 3D

Responsive interactive 3D structural viewer for three Kota Station drawings:

- Escalator support structure
- Curved façade steel frame
- 12.00 m cover-over-platform structure

The viewer includes source-drawing measurements, continuous Indian broad-gauge tracks, platforms, overhead equipment, station landscape and a Vande Bharat-inspired train pass every 30 seconds. It supports mouse, touch, phone, tablet and desktop layouts.

## Run locally

```bash
npm install
npm run dev
```

## Validate and build

```bash
npm run check
npm run build
```

The procedural models are visual interpretations. The supplied PDFs govern construction dimensions, reinforcement and connections.

The three original structural drawings and dimensioned 3D preview images are available in `public/assets/` and linked from each scene. The drawings govern construction details.
